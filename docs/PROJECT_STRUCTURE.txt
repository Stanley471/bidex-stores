# CUSTOMIZE THE HOMEPAGE
# ============================================================

Edit: src/config/store.config.ts

1. Disable a section:
   { id: 'promo-banner', enabled: false }

2. Change section order:
   { id: 'bestsellers', order: 2 }

3. Customize section:
   { id: 'featured-products', config: { displayLimit: 12 } }
